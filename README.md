# Marigold Bridge storyboard

An offline cue-sheet CLI for planning an original adult flower-bridge remembrance video. I build and maintain [Marigold Bridge AI](https://marigoldbridgeai.com/). This script only prints shot timing; it does not generate video, read portraits, call a model or require an account.

## Run

Python 3, standard library only:

```sh
python3 storyboard.py walk
python3 storyboard.py hug --json
```

The walk cue sheet covers 12 seconds: shoes enter petals, an adult crouches, gathers flowers, then a framed original portrait holds the ending. The hug cue sheet covers 10 seconds and assumes TWO separate adult identity images. These are intended storyboards, not measured compliance scores or promises that a model obeys every beat.

## Adapt and review

Use original scene design and permitted adult photos. Preserve the whole framed portrait at the ending, check hands and likeness, and identify shared clips as AI imagery. Do not claim Disney/Pixar affiliation or include their characters, footage or recorded songs. The [Coco-related search-intent page](https://marigoldbridgeai.com/coco-marigold-bridge-ai/) describes our independent decorative style and its limits. The [Heaven Hug workflow](https://marigoldbridgeai.com/heaven-hug-ai/) explains two-photo input requirements.

No network, credentials, private reference assets or customer data are included. Personalized generation on the linked website is paid; this planning helper is freely usable under MIT. AI assisted preparation; both output formats were run locally and checked for continuous timelines ending at 12 and 10 seconds.

For animal remembrance instead of adult portraits, see our separate [Day of the Dead Pet AI](https://dayofthedeadpet-ai.com/) project.
